# Проект YaMDb

Проект YaMDb собирает отзывы пользователей на произведения. Сами произведения в YaMDb не хранятся, здесь нельзя посмотреть фильм или послушать музыку.

## Описание

Произведения делятся на категории, такие как «Книги», «Фильмы», «Музыка». Например, в категории «Книги» могут быть произведения «Винни-Пух и все-все-все» и «Марсианские хроники», а в категории «Музыка» — песня «Давеча» группы «Жуки» и вторая сюита Баха. Список категорий может быть расширен (например, можно добавить категорию «Изобразительное искусство» или «Ювелирка»).

Произведению может быть присвоен жанр из списка предустановленных (например, «Сказка», «Рок» или «Артхаус»). Добавлять произведения, категории и жанры может только администратор.

Благодарные или возмущённые пользователи оставляют к произведениям текстовые отзывы и ставят произведению оценку в диапазоне от одного до десяти (целое число); из пользовательских оценок формируется усреднённая оценка произведения — рейтинг (целое число). На одно произведение пользователь может оставить только один отзыв.

Пользователи могут оставлять комментарии к отзывам. Добавлять отзывы, комментарии и ставить оценки могут только аутентифицированные пользователи.

Реализовано с помощью Django REST Framework.

## Основные возможности

- **Аутентификация** пользователей через JWT-токены
- **Комментирование** постов
- **Добавление,удаление, реактирование** произведений 
- **Рейтинг** произведений
- **Поиск и фильтрация** контента
- **Пагинация** результатов

## Технологии

- Python 3.12
- Django 5.1
- Django REST Framework
- SQLite (по умолчанию)

## Установка и запуск

1. **Создать и активировать виртуальное окружение**

```bash
   python -m venv venv
   source venv/bin/activate  # Linux/MacOS
   # или
   venv\Scripts\activate     # Windows
```

2. **Установить зависимости 'requirements.txt'**
   `pip install -r requirements.txt`

3. **Запустить сервер:**
   `python manage.py runserver`

**Эндпоинты**

## Регистрация нового пользователя

`/api/v1/auth/signup/ (POST): Регистрация нового пользователя.`
Пример ответа:

```
{
"email": "string",
"username": "string"
}
```

`/api/v1/auth/token/ (POST): Получение токена по коду подтверждения.`
Пример ответа:

```
{
  "token": "string"
}
```

`/api/v1/users/ (GET, POST): Список пользователей и создание нового (только для администратора).`
Пример ответа:

```
{
  "username": "^w\\Z",
  "email": "user@example.com",
  "first_name": "string",
  "last_name": "string",
  "bio": "string",
  "role": "user"
}
```

`/api/v1/users/{username}/ (GET, PATCH, DELETE): Получение, изменение или удаление пользователя (только для администратора).`
Пример ответа:

```
{
  "username": "^w\\Z",
  "email": "user@example.com",
  "first_name": "string",
  "last_name": "string",
  "bio": "string",
  "role": "user"
}
```

`/api/v1/users/me/ (GET, PATCH): Получение или изменение данных текущего пользователя.`

## Категории и жанры

`/api/v1/categories/ (GET, POST): Список категорий, создание новой (POST только для администратора).`
Пример ответа:

```
{
  "count": 0,
  "next": "string",
  "previous": "string",
  "results": [
    {
      "name": "string",
      "slug": "^-$"
    }
  ]
}
```

## Произведения

`/api/v1/titles/ (GET, POST): Список произведений, добавление нового (POST — только для администратора).`
Пример ответа:

```
{
  "count": 0,
  "next": "string",
  "previous": "string",
  "results": [
    {
      "name": "string",
      "slug": "^-$"
    }
  ]
}
```

## Отзывы

`/api/v1/titles/{title_id}/reviews/ (GET, POST): Список отзывов для произведения, добавление нового (POST — только для аутентифицированных).`
Пример ответа
```
{
  "count": 0,
  "next": "string",
  "previous": "string",
  "results": [
    {
      "id": 0,
      "name": "string",
      "year": 0,
      "rating": 0,
      "description": "string",
      "genre": [
        {
          "name": "string",
          "slug": "^-$"
        }
      ],
      "category": {
        "name": "string",
        "slug": "^-$"
      }
    }
  ]
}
```
## Комментарии

`/api/v1/titles/{title_id}/reviews/{review_id}/comments/ (GET, POST): Список комментариев к отзыву, добавление нового (POST — только для аутентифицированных).`
Пример ответа
```
{
  "count": 0,
  "next": "string",
  "previous": "string",
  "results": [
    {
      "id": 0,
      "text": "string",
      "author": "string",
      "pub_date": "2019-08-24T14:15:22Z"
    }
  ]
}
```
